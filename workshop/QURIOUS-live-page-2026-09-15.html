Description
怪异炼化 - 遗物 / Qurious Crafting - Relics

每局游戏,用东尼算法从本局种子确定性地生成 60 件混沌遗物,替换本局全部的随机遗物掉落.点数预算制:正面词条按点数购置,负面词条返还点数。
Every run, deterministically generate 60 chaos relics from the run seed and replace all random relic drops. Point-budget crafting: buy positive entries with points, sell debuffs back for more.



它做什么 / What it does

  • 60 件生成遗物 - 每局从种子派生:20 普通 / 20 罕见 / 20 稀有
  • 点数预算 - 稀有度决定预算(默认 普通 12 / 罕见 18 / 稀有 25),正面词条按点数购置
  • 负面词条 - 按稀有度概率出现一条负面(默认 5% / 25% / 75%),返还点数换取更强正面
  • 词条数量 - 默认 3 条为主,全局倍率最高可拉到 5 条
  • 动态描述 - 提示框逐行显示本局的实际效果与数值,所见即所得
  • 确定性 - 同种子 = 同一批遗物;开局冻结配置,局内改设置或重读存档都不会让已获得的遗物变义

词条模板 / Templates

核心 36 条(正面 26 + 负面 10):
  • 战斗开始:伤害 / 格挡 / 力量 / 敏捷 / 抽牌 / 能量 / 覆甲 / 中毒 / 再生 / 荆棘 / 易伤 / 虚弱 / 人工制品
  • 回合开始:格挡 / 抽牌 / 能量 / 回复生命
  • 打出卡牌:获得格挡 / 随机敌人伤害
  • 被动:攻击伤害 / 格挡加成 / 金币 / 能量上限
  • 战斗胜利:金币 / 回复;营火:休息回复加成
  • 负面:自身易伤 / 出牌上限 / 每回合失去生命 / 能量上限- / 每回合抽牌- / 金币获得- / 攻击伤害- / 营火回复- / 无法获得药水 / 虚弱开场 / 迟滞开场 / 生命上限-

额外池(默认关闭,共 15 条):附魔三系 锋利 / 灵巧 / 注能(结算入口 + 拾取入口)、手牌 保留 / 奇巧 / 虚无、保留触发(攻击强化 / 能量折扣)、观者姿态 平静 / 愤怒 / 神格(需安装观者 Watcher)。

替换范围 / Scope

  • 战斗 / 精英 / 宝箱 / 商店 / 事件 / 挖掘 / 营火 —— 全部只出混沌遗物;耗尽后回落游戏原生兜底
  • 先古之民(Ancient)遗物完全不动;初始遗物 / Neow / 事件专属固定遗物本就不经过奖励池

游戏内设置 / Settings

主菜单 设置 → 常规 → Qurious Crafting - Relics(专属设置页,与东尼算法本体入口相邻):
  • 启用混沌遗物 —— 总开关;关闭后奖励池恢复原版遗物
  • 点数预算 / 负面概率 —— 普通 / 罕见 / 稀有 三档独立可调
  • 点数预算编辑器 —— 每个模板的数值区间(双端滑条)与每点价格实时编辑,悬停原版遗物名可对照参考
  • 恢复默认设置

联机 / Multiplayer

同种子 + 相同配置 = 双端完全一致。推荐搭配 MpConfigSync(开局自动把主机配置下发给全队,配置文件全程冻结,会话结束自动还原,只影响本局)。

兼容 / Compatibility

  • 与 Auto-Anthonyology(东尼算法) 同装自由,互不依赖
  • 与 Anthony Algorithm - Relics(东尼算法 - 遗物) 同装:双方都做遗物池替换,最终掉落受加载顺序影响,组合体验以实测为准
  • 内置 遗物三选一 + Act4Heart 蓝钥匙修复:同时安装 RelicRewardChoices 与 Act4Heart 时,宝箱跳过会正确补发蓝钥匙

前置 / Requirements

  • 必须:BaseLib

BaseLib 版本提示:工坊版常落后于官方 GitHub;游戏更新后若报错,前往 GitHub Releases[github.com] 下载最新版解压进 mods 目录,并取消订阅工坊版避免双加载。

控制台验证 / Console test

局内按 ` 打开开发者控制台:
relic add QURIOUSCRAFTINGRELICS-CHAOS_RELIC005
