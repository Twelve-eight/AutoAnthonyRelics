[h1]AutoAnthony - Relics(东尼算法 - 遗物)[/h1]

每局游戏,用东尼算法从本局种子确定性地生成 60 件混沌遗物,并替换本局全部的遗物掉落.

[h2]它做什么[/h2]

开局时,本 mod 依据本局种子生成 60 件混沌遗物(混沌遗物 1-60).每一件都有:
[list]
[*][b]随机名字[/b] - 形容词 + 名词组合
[*][b]点数预算[/b] - 稀有度决定预算(默认 普通 10 / 罕见 16 / 稀有 24),正词条按点数购置
[*][b]负面词条[/b] - 概率出现一条负面效果,返还点数换取更多正词条(怪猎炼化风格)
[*][b]随机稀有度[/b] - 20 普通 / 20 罕见 / 20 稀有,逐种子重新生成
[*][b]动态描述[/b] - 遗物提示框实时显示本局的具体效果列表(逐行中文)
[/list]

同种子 = 同一批遗物;换种子 = 同一槽位完全不同的词条.

[h2]遗物替换[/h2]

以下全部遗物来源都只出混沌遗物:
[list]
[*]战斗奖励 / 精英奖励
[*]宝箱
[*]商店
[*]事件的随机遗物
[*]挖掘 / 营火等
[/list]

保持原版不受影响的:
[list]
[*][b]先古之民(Ancient)遗物[/b] - 完全不动
[*]初始遗物 / Neow 遗物 / 事件专属固定遗物(本就不经过奖励池)
[/list]

混沌遗物耗尽后回落到游戏原生兜底行为.

[h2]词条效果模板(共 47: 核心 26 正 + 10 负,额外池 10 正 + 1 负)[/h2]

[list]
[*][b]战斗开始[/b]:对全体敌人伤害 / 格挡 / 力量 / 敏捷 / 抽牌 / 能量 / 全体易伤 / 全体虚弱 / 再生 / 荆棘 / 人工制品 / 全体中毒 / 覆甲
[*][b]回合开始[/b]:格挡 / 能量 / 回复生命 / 抽牌
[*][b]打出卡牌[/b]:对随机敌人伤害 / 获得格挡
[*][b]被动[/b]:攻击伤害加成 / 能量上限加成 / 格挡加成 / 金币加成 / 营火回复加成
[*][b]战斗胜利[/b]:回复生命 / 获得金币
[*][b]负面词条[/b]:自身脆弱 / 自身出牌上限 / 每回合失去生命 / 能量上限- / 每回合抽牌数- / 金币获得- / 攻击伤害- / 营火回复- / 无法获得药水 / 获得时最大生命值-
[/list]

额外池(默认关闭):手牌保留 / 奇巧 / 虚无,附魔(锋利 / 灵巧 / 注能),保留触发,观者姿态(需安装观者 mod).

[h2]游戏内设置[/h2]

设置 -> 常规 -> 东尼算法 - 遗物(专属设置页,与东尼算法本体入口相邻):
[list]
[*][b]启用混沌遗物[/b] - 总开关.关闭后:混沌遗物不再生成,奖励池恢复原版遗物,已拥有的混沌遗物效果停用
[*][b]点数预算[/b] - 普通 / 罕见 / 稀有 各自的预算(默认 10 / 16 / 24)
[*][b]负面词条概率[/b] - 各稀有度出现负面词条的概率(默认 35% / 55% / 75%)
[*][b]点数预算编辑器[/b] - 每个词条模板的点数与数值区间(双手柄范围滑条)
[*]恢复默认设置按钮
[/list]

进阶:每个模板的点数同时是配置文件键(Cost_ / Refund_ 前缀,详见 mod 目录文档).

[h2]多人联机[/h2]

同种子两端确定性生成同一批遗物(预算/点数/区间配置也必须一致);随机目标使用游戏的播种随机通道(CombatTargets),不破坏联机同步.
