[h1]怪异炼化 - 遗物 / Qurious Crafting - Relics[/h1]

每局游戏,用东尼算法从本局种子确定性地生成 60 件混沌遗物,替换本局全部的随机遗物掉落.点数预算制:正面词条按点数购置,负面词条返还点数,像怪物猎人的炼化一样攒出你的专属神装.

[i]Every run, deterministically generate 60 chaos relics from the run seed and replace all random relic drops. Point-budget crafting: buy positive entries with points, sell debuffs back for more.[/i]

[hr]

[h2]它做什么 / What it does[/h2]

[list]
[*][b]60 件生成遗物[/b] - 每局从种子派生:20 普通 / 20 罕见 / 20 稀有
[*][b]点数预算[/b] - 稀有度决定预算(默认 普通 12 / 罕见 18 / 稀有 25),正面词条按点数购置
[*][b]负面词条[/b] - 按稀有度概率出现一条负面(默认 5% / 25% / 75%),返还点数换取更强正面
[*][b]词条数量[/b] - 默认 3 条为主,全局倍率最高可拉到 5 条
[*][b]动态描述[/b] - 提示框逐行显示本局的实际效果与数值,所见即所得
[*][b]确定性[/b] - 同种子 = 同一批遗物;开局冻结配置,局内改设置或重读存档都不会让已获得的遗物变义
[/list]

[h2]替换范围 / Scope[/h2]

[h2]游戏内设置 / Settings[/h2]

主菜单 设置 → 常规 → [b]Qurious Crafting - Relics[/b](专属设置页,与东尼算法本体入口相邻):
[list]
[*]启用混沌遗物 —— 总开关;关闭后奖励池恢复原版遗物
[*]点数预算 / 负面概率 —— 普通 / 罕见 / 稀有 三档独立可调
[*][b]点数预算编辑器[/b] —— 每个模板的数值区间(双端滑条)与每点价格实时编辑,悬停原版遗物名可对照参考
[*]恢复默认设置
[/list]

[h2]联机 / Multiplayer[/h2]

同种子 + 相同配置 = 双端完全一致。推荐搭配 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3799210379]MpConfigSync[/url](开局自动把主机配置下发给全队,配置文件全程冻结,会话结束自动还原,只影响本局)。
