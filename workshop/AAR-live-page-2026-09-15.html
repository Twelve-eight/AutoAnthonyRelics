Description
东尼算法 - 遗物 / Anthony Algorithm - Relics

每局游戏,用东尼算法从本局种子确定性地生成 60 件遗物,并替换本局全部的遗物掉落.
与原版东尼算法相同的核心机制:触发与效果是独立片段,生成时随机重组 ——
任何合法的触发条件都可能挂上任何合法的效果,包括原版从未存在过的组合.
Every run, deterministically generate 60 relics from the run seed and replace all relic drops. Triggers and effects are independent fragments recombined at generation time - the Anthony algorithm applied to relics.



它做什么 / What it does

  • 60 件生成遗物 - 每局从种子派生,逐槽位重新生成(20 普通 / 21 罕见 / 19 稀有附近分布)
  • 条件重组 - 触发片段(回合开始 / 回合结束 / 战斗开始 / 战斗结束 / 战斗胜利 / 进入战斗 / 拾取时 / 打出能力牌 / 敌人死亡 / 获得金币 / 格挡被清空)与效果片段(力量 / 活力 / 荆棘 / 全体易伤 / 格挡 / 回复 / 能量 / 抽牌 / 生命上限 / 金币 / 药水栏位 / 全体伤害)从同一个池子独立采样
  • 双效果遗物 - 约 30% 的遗物携带两个效果,同挂一个触发
  • 纯被动遗物 - 少数遗物是首回合抽牌修正(正负都有)
  • 中英双语描述 - 每件遗物的名字与描述由片段语义实时渲染
  • 确定性 - 同种子 = 同一批遗物(逐字节一致);定义不读任何设置项,读档/重连恢复同一批

数据忠实度 / Data fidelity

原子池从游戏自身的 300 个遗物类提取,并经过逐条人工审计账本过滤:
只有证据完整、六项对账(何时/谁/目标/数值/条件/状态)全部通过的片段进入生成池;
提取器无法核实或提取错误的条目(阈值当数值 / 正负号丢失 / 条件反转等)一律拒绝.
已知修复示例:水银玉猫袋(全体 1 易伤)、大蘑菇(首回合少抽 2 张,负号保留)、
弯刀(力量 1)、药水腰带(2 个栏位).
Atoms are extracted from the game's own 300 relic classes and gated by a hand-audited deny-by-default ledger; unverifiable extractions never reach the pool.

遗物替换范围 / Relic replacement

以下全部遗物来源只出生成遗物:
  • 战斗奖励 / 精英奖励 / 宝箱 / 商店 / 事件的随机遗物 / 挖掘 / 营火等

保持原版不受影响的:
  • 先古之民(Ancient)遗物 - 完全不动
  • 初始遗物 / Neow 遗物 / 事件专属固定遗物(本就不经过奖励池)

游戏内设置 / In-game settings

设置 -> 模组设置(专属设置页):
  • Enabled(总开关) - 关闭后生成遗物停用,奖励池恢复原版
  • ReplaceVanillaRelics(替换原版遗物) - 关闭后生成遗物与原版遗物混合掉落
  • 其他 BaseLib 遗物模组的自定义遗物自动保留,无需单独开关

与 怪异炼化 - 遗物 共存 / Coexistence with Qurious Crafting

可与 Qurious Crafting - Relics(怪异炼化 - 遗物) 同装:本模组的替换会保留 BaseLib 自定义遗物,但 Qurious 的掉落池只保留它自己的混沌遗物,双装时实际掉落以 Qurious 为主,组合体验请以实测为准.
Can be installed alongside Qurious Crafting - Relics; note that Qurious's pool replacement keeps only its own chaos relics, so with both installed drops skew toward Qurious. Test your combination.

多人联机 / Multiplayer

遗物定义是种子与槽位的纯函数,不读取任何设置项:同种子两端生成同一批遗物.
设置项只控制本机行为(开关/替换范围),不影响生成内容.
Definitions are a pure function of the run seed and slot - no config participates, so both ends regenerate identical relics.



署名与数据来源 / Attribution

  • 机制:条件与效果独立采样、种子确定性重组,来自 Alriph 的 Auto-Anthonyology(东尼算法) 的思想重写;本 mod 与其相互独立,不依赖也不重复其数据
  • 原子数据:由本模组工具从《杀戮尖塔 2》自身遗物实现中提取,经人工审计账本过滤
  • 生成器 / 宿主 / 渲染:本仓库独立实现

前置依赖 / Requirements

  • 必须:BaseLib 3.4.5+

工坊版 BaseLib 更新经常落后于官方 GitHub;游戏更新后若 BaseLib 报错,请到 GitHub Releases[github.com] 下载最新版并取消订阅工坊版.

控制台验证(可选)/ Console test

局内按 ` 打开开发者控制台:
relic add AUTOANTHONYRELICS-ANTHONY_RELIC005
(添加第 6 号槽位生成遗物)
