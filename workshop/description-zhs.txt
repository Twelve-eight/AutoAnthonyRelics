[h1]AutoAnthony - Relics(东尼算法 - 遗物)[/h1]

每局游戏,用东尼算法从本局种子确定性地生成 60 件混沌遗物,并替换本局全部的遗物掉落.

[hr]

[h2]它做什么[/h2]

开局时,本 mod 依据本局种子生成 60 件混沌遗物(混沌遗物 1-60).每一件都有:
[list]
[*][b]随机名字[/b] - 形容词 + 名词组合
[*][b]随机词条[/b] - 每件 1 / 3 / 5 条(加权随机),来自 16 种效果模板
[*][b]随机稀有度[/b] - 20 普通 / 20 罕见 / 20 稀有,逐种子重新生成
[*][b]动态描述[/b] - 遗物提示框实时显示本局的具体效果列表(逐行中文)
[/list]

同种子 = 同一批遗物;换种子 = 同一槽位完全不同的词条.

[h2]遗物替换范围[/h2]

以下全部遗物来源都只出混沌遗物:
[list]
[*]战斗奖励 / 精英奖励
[*]宝箱 / 商店
[*]事件的随机遗物
[*]挖掘 / 营火等
[/list]

保持原版不受影响的:
[list]
[*][b]先古之民(Ancient)遗物[/b] - 完全不动
[*]初始遗物 / Neow 遗物 / 事件专属固定遗物(本就不经过奖励池)
[/list]

混沌遗物耗尽后回落到游戏原生兜底行为.

[h2]词条效果模板(16 种)[/h2]

[list]
[*][b]战斗开始[/b]:对全体敌人伤害 / 获得格挡 / 力量 / 敏捷 / 抽牌 / 能量 / 施加易伤 / 施加虚弱
[*][b]回合开始[/b]:格挡 / 能量 / 回复生命
[*][b]打出卡牌[/b]:对随机敌人伤害 / 获得格挡
[*][b]被动[/b]:攻击伤害加成 / 能量上限加成
[*][b]战斗胜利[/b]:回复生命
[/list]

[h2]游戏内设置[/h2]

设置 -> Mod 设置 -> AutoAnthony - Relics:
[list]
[*][b]启用混沌遗物[/b] - 总开关.关闭后:混沌遗物不再生成,奖励池恢复原版遗物,已拥有的混沌遗物效果停用
[*][b]词条档位基准[/b] - 词条数量档位.默认 3(即 1/3/5 条);调高整体上移词条数
[*]恢复默认设置按钮
[/list]

[h2]多人联机[/h2]

同种子两端确定性生成同一批遗物;随机目标使用游戏的播种随机通道,不破坏联机同步.
