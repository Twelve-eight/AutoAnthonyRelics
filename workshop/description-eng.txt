[h1]AutoAnthony - Relics (Dongni Algorithm - Relics)[/h1]

Every run, deterministically generate 60 chaos relics from the run seed and replace all relic drops.

[hr]

[h2]What it does[/h2]

At run start, this mod generates 60 chaos relics (Chaos Relic 1-60) from the run seed. Each one has:
[list]
[*][b]Random name[/b] - adjective + noun combination
[*][b]Point budget[/b] - each relic gets a rarity-scaled point budget (10 / 16 / 24 by default), and positive entries are bought with those points
[*][b]Negative entries[/b] - a chance of one negative effect, which refunds points to buy even more positives (Monster Hunter qurious-crafting style)
[*][b]Random rarity[/b] - 20 common / 20 uncommon / 20 rare, regenerated per seed
[*][b]Dynamic description[/b] - the relic tooltip shows this run's actual effect list, line by line
[/list]

Same seed = the same relic set; new seed = completely different affixes in the same slots.

[h2]Relic replacement[/h2]

All of these relic sources drop only chaos relics:
[list]
[*]Combat rewards / elite rewards
[*]Chests / shops
[*]Random relics from events
[*]Digging / campfires and more
[/list]

Left untouched:
[list]
[*][b]Ancient relics[/b] - never replaced
[*]Starting relics / Neow relics / fixed event relics (never go through the reward pool anyway)
[/list]

When chaos relics run out, the game falls back to native behavior.

[h2]Effect templates (47: 26 + 10 core positives/negatives, 10 + 1 extra)[/h2]

[list]
[*][b]Combat start[/b]: damage to all enemies / block / Strength / Dexterity / draw / energy / Vulnerable to all / Weak to all / Regen / Thorns / Artifact / Poison to all / Plating
[*][b]Turn start[/b]: block / energy / heal / draw
[*][b]Play a card[/b]: damage to a random enemy / block
[*][b]Passive[/b]: attack damage bonus / max energy bonus / block bonus / gold bonus / rest-site heal bonus
[*][b]Combat victory[/b]: heal / gold
[*][b]Negative entries[/b]: self Frail / self card-play cap / HP loss per turn / max energy down / draw down / gold down / attack damage down / rest heal down / no potions / max HP down on pickup
[/list]

Extra pool (off by default): hand retain / sly / ethereal, enchantments (Sharp / Nimble / Imbued), retain triggers, and Watcher stances (requires the Watcher mod).

[h2]In-game settings[/h2]

Settings -> General -> AutoAnthony - Relics (its own page, next to AutoAnthony's):
[list]
[*][b]Enable Chaos Relics[/b] - master switch. Off: chaos relics stop generating, the reward pool restores vanilla relics, owned chaos relics stop working
[*][b]Point budget[/b] - Common / Uncommon / Rare budgets (default 10 / 16 / 24)
[*][b]Negative chance[/b] - per-rarity chance of a negative entry (default 35% / 55% / 75%)
[*][b]Budget editor[/b] - per-template point costs and amount ranges (double-ended range sliders)
[*]Restore defaults button
[/list]

Advanced: every per-template point value is also a cfg key (Cost_ / Refund_ prefixes, see the mod folder docs).

[h2]Multiplayer[/h2]

Both ends deterministically generate the same relic set from the same seed and the same budget/cost/range config; random targeting uses the game's seeded channel, so multiplayer sync is preserved.
