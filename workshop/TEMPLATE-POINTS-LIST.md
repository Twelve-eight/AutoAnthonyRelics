# 词条点数清单 - v0.5 预算系统

> 本表由 `mod/Code/Chaos/ChaosRelicCatalog.cs` (核心池) 与
> `mod/Code/Chaos/ChaosRelicExtraCatalog.cs` (额外池) 直接导出;
> **两个目录文件是唯一事实源**, 改价/改区间请改目录文件 (以及
> `QuriousCraftingRelicsConfig` 的同名配置默认值) 后重新同步本表, 不要只改表.

模板总数 **47** = 核心正面 26 + 核心负面 10 + 额外池正面 10 + 额外池负面 1
(额外池默认关闭, 开启后加入生成池; 观者姿态 3 项还需要安装观者 mod).

## 生成规则 (ChaosRelicGenerator)

1. 每件遗物按稀有度取预算 = `max(配置预算, 最便宜正面词条的下限价)` - 该下限保证
   每件遗物至少有 1 条正面词条. 默认预算: 普通 10 / 罕见 16 / 稀有 24.
2. 花预算买正面词条: 在"下限价 <= 剩余预算"的模板中均匀随机, 数值在其区间内掷出,
   超出剩余预算时向下压缩到买得起的最大数值; 单件最多 6 条正面, 同一模板至多 1 条
   (每回合能量 / 每回合抽牌 / 能量上限为唯一性模板).
3. 掷负面: 概率默认 普通 35% / 罕见 55% / 稀有 75%, 每件至多 1 条负面.
4. 负面返还 = `每点返还 x 数值`; 返还点数按第 2 步继续买正面词条.
5. 同一局内避免重复的"效果集合"(同模板集合最多重掷 4 次).

**三角计价 (衰减型词条)**: 再生 / 全体中毒 / 覆甲 的层数价值递减 (第 N 层只结算
N 次), 所以第 N 层比第 1 层贵, 总花费

    总花费 = 每点成本 x N x (N + 1) / 2

例: 全体中毒 每点 1 -> 6 层 = `1 x 6 x 7 / 2` = 21 点. 表中带 (三角) 标记的即此类.

## 实测生成分布 (隔离探针, 45 种子 x 60 件 = 2700 件, 2026-09-12)

- 正词条均值: 普通 2.91 / 罕见 3.84 / 稀有 4.84
- 负面率: 37.6% / 57.4% / 76.3%
- 正面花费均值 (含负面返还): 14.46 / 22.71 / 31.87 (默认预算 10 / 16 / 24;
  大于预算来自返还点数, 不代表超支)

## 调整方式

- 预算 / 负面概率: 游戏内 设置 -> 常规 -> 怪异炼化 - 遗物 -> 打开设置 (专属设置页)
- 每词条点数与数值区间: 设置页内的滑条 (区间为双手柄范围滑条), 或直接改
  `mod_configs/QuriousCraftingRelics.cfg`
  (键名与配置属性同名, 例: `"Cost_C_START_STRENGTH": "4"`, `"Refund_N_GOLD_DOWN": "3"`)
- 注意: 联机时两端预算/概率/点数/区间必须一致 (生成确定性键)
